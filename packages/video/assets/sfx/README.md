# Sound effects

The recorded sounds AppStory plays under a video: a click when the pointer clicks, and key
presses while a value is typed (see `packages/video/src/audio.ts`). All are CC0 (public
domain): free to use and to publish, with no credit needed.

| File | Source | Licence |
| --- | --- | --- |
| `click-1.ogg`, `click-2.ogg`, `click-3.ogg` | `click_002`, `click_003`, `click_005` from [Interface Sounds](https://kenney.nl/assets/interface-sounds) by Kenney | CC0 1.0 |
| `key-1.ogg` … `key-8.ogg` | `keypress-003`, `-007`, `-008`, `-010`, `-011`, `-014`, `-015`, `-016` from [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes) by unicae_games | CC0 1.0 |

The clicks are unchanged. Each key press is set to the same peak level (-6 dBFS) and saved
as Ogg Vorbis, so no single key sounds louder than the others.
