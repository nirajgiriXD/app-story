# Projectly — what's new

## Create a project

Start a new project from the Projects list.

- Where: the **+ New project** button on the Projects page (`/projects`).
- How: fill in *Project name* (for example "Q3 Product Launch"), add a short *Description*,
  pick a *Status*, then click **Create project**.
- Done when: you are back on the Projects list, a confirmation appears and the new project is highlighted.
