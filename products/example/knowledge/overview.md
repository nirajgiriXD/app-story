# Projectly overview

Projectly is a project tracker for small teams.

## Areas

- **Projects** (`/projects`): list of all projects with status counts (Planning, In progress, On hold).
  The **+ New project** button opens a form.
- **New project** (`/projects/new`): fields *Project name* (required), *Description*, *Status* and *Owner*.
  **Create project** saves it and returns to the list, where a confirmation appears and the new project is highlighted.
- **Project detail** (`/projects/<id>`): status, owner and creation date.
- **Team** (`/team`): team members.
- **Settings** (`/settings`): workspace settings.
